# XVER Main GUI Installer

ไฟล์นี้ไม่มี Discord Token หรือ Webhook

## สร้างแอปบน Windows
เปิด PowerShell แบบ Administrator แล้วรัน:

```powershell
irm 'https://raw.githubusercontent.com/khribwangi-sys/xver-main-installer/main/build-xver-gui.ps1' | iex
```

สคริปต์จะถาม Token ตอนสร้าง/ใช้งาน และสร้าง `xver-main.exe` บน Desktop
